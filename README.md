# 🚀 Dream Track | Premium Academic & Productivity Dashboard

Dream Track is a high-performance, personalized study management engine designed for students. Built with React.js and SASS, it integrates Firebase Cloud Services to provide real-time data syncing, progress tracking, and gamified productivity tools.

![React](https://shields.io)
![Firebase](https://shields.io)
![SASS](https://shields.io)
![Vercel](https://shields.io)

---

## ✨ Key Features

### 🔐 1. Secure Authentication

- Google OAuth: One-tap login via Firebase Authentication.
- Email/Password: Traditional login and registration support.
- User Profiles: Personalized dashboards with Google profile sync.

### 🌳 2. Gamified Focus Forest (Pomodoro 2.0)

- Growth Visualization: Focus sessions "plant" digital trees that grow from seeds to full-grown trees over time.
- Ambient Nature Audio: High-quality background nature sounds (Rain/Forest) that play during focus sessions.
- Overtime Tracker: Automatically counts bonus study time once the focus target is met.
- Weekly Growth: A historical forest view that visualizes consistency over the past 7 days.

### 📊 3. Performance Analytics

- Recharts Integration: Visualizes past paper score trends for Maths, Physics, and Chemistry.
- Subject Mastery: Real-time calculation of subject-wise averages and highest marks.

### 📅 4. Adaptive UI & Layout

- Cross-Platform Support: Fully responsive design.
- Bottom Navigation: Mobile-first navigation bar (Instagram-style) for seamless mobile usage.
- Smart Timetable: Automated weekly study schedule that resets and archives every Monday.

---

## 🛠️ Technical Stack

- Framework: React.js (Functional Components, Hooks, Refs)
- State Management: React Hooks & Firebase Real-time Sync
- Backend: Firebase (Auth & Firestore Database)
- Data Visualization: Recharts (Line Charts)
- Styling: SASS (Mixins, Grid/Flex Layouts, Custom Animations)
- Icons: Lucide React, React Icons

## 🚀 Getting Started

1. Clone the repository

   git clone https://github.com

2. Install dependencies

   npm install

3. Configure Firebase
   - Create a firebase.js in the src folder.
   - Add your Firebase Config (API Key, AuthDomain, etc.).
4. Run the App

   npm run dev
